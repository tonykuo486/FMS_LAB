## 0. 里程碑與閘門 (Gate) 總覽

```
W1        W2        W3        W4      W5      W6        W8        W10       W12
├─WP0 治理啟動─┤
├─WP1 基準量測────┤
     ├─WP2 [新元件建置]──[G1]──觀察 7 天─┤
     ├─WP3 核實補強────────┤
     ├─WP4 事件服務開發──────────────────────┤
                                    ├─WP5 召回率─[G2]─┤
                                           ├─WP6 Shadow 對帳 14 天─[G3]─┤
                                                                ├─WP7 切換─[G4]─觀察 30 天
[G0 Kickoff]
```

| Gate | 判定條件 | 判定者 | 不過怎麼辦 |
|---|---|---|---|
| **G0** 開工放行 | RACI + 商業驅動簽認; WP0 全數完成 | SPO | 補齊再開 |
| **G1** [技術閘門, 例: 效能實測] | [具體門檻] | SPO ([角色] 提報) | 回退 ADR-N → 重開偵測機制 ADR |
| **G2** 召回率 | [業務指標] ≈ [目標] | SPO (QA 提報) | 修反查 / 擴大策略, 重驗 |
| **G3** Shadow 零差異 | 連續 14 天 shadow vs 正式 diff = 0 | SPO (QA 提報) | 差異調查迴圈 (06 §4), 重新計天 |
| **G4** 切換放行 | G1-G3 過 + UAT 過 + 回滾演練過 + 值班 SOP 就緒 | SPO (BIZ 諮詢) | 延後, shadow 續跑 |
