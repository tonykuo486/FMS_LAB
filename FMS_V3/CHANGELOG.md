# CHANGELOG — [PROJECT_NAME]

> **用法**: cp 後保留本說明框,首條目從專案第一個里程碑開始寫。
> **為什麼必要(Claude Code 視角)**: `CLAUDE.md` 是**靜態脈絡**(架構/規範,每 session 載入),
> 本檔是**時間脈絡**——新 session 的 AI 與接手的人靠它知道「最近改了什麼、為什麼、
> 驗過沒有」。沒有它,AI 只能從 git log 考古,貴且容易漏。
> **原料**: commit message=核實紀錄(現象→證據→修法→實測數字)——重大變更把核實
> 紀錄彙整成一條目;瑣碎 commit 不入檔。
>
> **格式鐵律**:
> 1. **最新在上**;條目=`## YYYY-MM-DD — ★一句話標題`。
> 2. 內文寫**變化點+驗證證據**(數字/測試結果),不寫流水帳。
> 3. 涉及決策 → 只寫結論+指向 `docs/99_決策紀錄_ADR.md` 的編號,不重抄理由。
> 4. 交接以文件為準:本檔頭部固定放文件地圖指針(README → docs → ADR)。
> 5. 版本號出現時(如 `be 0.1.x rollout`)必寫進條目——回滾時靠它對時間軸。
